# Chat Chaos 3 - Minecraft 26.3 (Fabric)

Чат Twitch голосует, что случится со стримером. Оверлей рисуется в игре, настройки в меню,
эффекты лежат в обычных JSON-файлах - имя файла и есть название (id) эффекта.

## Быстрый старт
1. Положи jar и Fabric API в `mods` (нужны Minecraft 26.3, Fabric Loader 0.19.5+, Java 25).
2. В мире: `/chaos menu` - откроется меню. Впиши канал Twitch, нажми «Подключить».
   Токены не нужны, чат читается анонимно.
3. Проверка без стрима: `/chaos fake vasya 2`, `/chaos test giant`.

## Меню (`/chaos menu`)
HUD вкл/выкл и сторона · длительность голосования и паузы · **сложность** (чилл / обычная / ад: меняет долю «Беды»)
· **безопасный режим** (при <= 4 сердцах опасные эффекты не предлагаются) · **фильтр ников** · TNT и телепорт
· автозапуск · канал и ник стримера · **список эффектов**: включить/выключить, вес (0 - 3), кнопка «>» запускает тест.
Всё сохраняется сразу (настройки в `config/chatchaos.properties`, эффекты в своих файлах).

## Эффекты в файлах
Папка `config/chatchaos/effects/`. При первом запуске туда копируются 42 готовых эффекта. Правь их как угодно,
удаляй (удалённые не возвращаются) или кидай новые. После правок: `/chaos reload`.
Файлы разбираются один раз при загрузке: команды заранее режутся на части, во время игры только подставляются значения.
Если файл сломан, он пропускается, остальные работают (смотри `logs/latest.log`).

Пример `config/chatchaos/effects/my_effect.json`:
```json
{
  "title": "Дождь из зрителей-куриц и громкий салют",
  "category": "FUN",
  "group": "",
  "duration": 20,
  "weight": 1.0,
  "enabled": true,
  "danger": false,
  "needs": "",
  "pulseEvery": 30,
  "start": ["!say {nick} запустил шоу!"],
  "pulse": ["*2 execute at {player} run summon chicken {sky} {CustomName:\"{viewer}\",CustomNameVisible:1b}"],
  "end": []
}
```
Поля: `category` GOOD/BAD/FUN · `duration` секунды (0 = мгновенный) · `group` (эффекты одной группы не идут вместе)
· `weight` шанс выпадения (0 = выключен) · `danger` (прячется в безопасном режиме) · `needs` `destructive` или `teleport`
· `pulseEvery` тики между строками `pulse` · `start` / `pulse` / `end` - списки команд.

Строки: обычная команда Minecraft (без `/`), либо
`*5 команда` повторить 5 раз · `@40 команда` через 40 тиков · `!say текст` сообщение в чат игры.

Плейсхолдеры: `{player}` ник игрока (строка выполнится для каждого целевого игрока) · `{viewer}` случайный зритель
· `{nick}` один зритель на весь эффект · `{rand:a:b}` · `{pick:a|b|c}` · `{cycle:a|b}` по очереди · `{var:имя:a|b}`
выбрать один раз и помнить · `{ring}` / `{sky}` позиция рядом / в небе · `{neg}` · `{color}` · `{pitch}` · `{i}` и `{i:N}` номер повтора.

## HUD
Таймер, 3 варианта с процентами, список активных эффектов с отсчётом, топ чата, статус Twitch.
Работает в одиночном мире и у хоста LAN.

## Зрительские команды вне голосования (кулдаун 15 с)
`!boo` · `!cheer` · `!oops`

## Команды
`/chaos menu · connect <канал> · disconnect · start · stop · skip · clear · reset · reload · status · list`
`/chaos test <эффект> · fake <ник> <текст>`

## Фильтр ников
Включён по умолчанию: ники со словами из `blockedWords` (с учётом замен вида 0->o, 1->i) заменяются на `ViewerNNN`.
Список в `config/chatchaos.properties` через запятую, дополняй под свой чат.

## Если не собирается
Код написан без возможности скомпилировать (нет доступа к Minecraft). API экранов и HUD взяты из документации
Fabric для 26.1.2; в 26.3 имена могли немного измениться - компилятор покажет строку.
При проблемах с плагином Loom создай пустой проект на fabricmc.net/develop/template для 26.3
и перенеси в него `src/`.

## Получить jar без установки Java (GitHub Actions)
1. Создай пустой репозиторий на github.com и загрузи в него содержимое этой папки (вместе с `.github`).
2. Вкладка Actions -> build -> Run workflow (или просто сделай commit).
3. Через пару минут скачай артефакт `chatchaos-jar` - внутри готовый jar для папки `mods`.
